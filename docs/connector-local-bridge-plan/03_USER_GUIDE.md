# 접속기 로컬 브리지 — 사용 가이드

접속기(v0.12.1+)가 **사용자 로컬 ↔ Geny 웹 에이전트**를 잇는 통로가 되어, 서버의 에이전트가
내 컴퓨터를 보고·조작하고, 내 로컬 MCP 서버의 도구를 쓸 수 있습니다.

## 켜기
1. **접속기 업데이트** → v0.12.1 이상 (설정에 **제어 / MCP** 탭이 보이면 최신).
2. **접속기 설정 → 제어**: 로컬 컴퓨터 제어 마스터 ON + 원하는 능력(화면 보기 / 입력 / 앱·URL / 클립보드)
   + 동의 모드(항상 확인 / 이 세션 동안 허용 / 자동).
3. **VTuber 세션을 재시작** (도구는 세션 빌드 시점에 붙습니다. 최초 1회만 필요).
   - VTuber 역할 세션은 자동으로 컴퓨터 제어 + 로컬 MCP 도구를 갖습니다(별도 환경 설정 불필요).

## 컴퓨터 제어 (Computer Use)
에이전트가 쓰는 도구 (전부 실기기, 접속기 경유):
- `desktop_screenshot` — 화면을 캡처해 **모델이 직접 봄**(비전). 클릭 전에 먼저 찍어 좌표를 잡음.
- `desktop_click(x,y)` — 스크린샷 이미지에서 본 픽셀 좌표로 클릭.
- `desktop_type` / `desktop_key` — 타이핑 / 키 조합.
- `desktop_scroll(amount)` — 휠 스크롤(+아래 / -위).
- `desktop_open_app` / `desktop_clipboard_write` — 앱·URL 열기 / 클립보드.
- `desktop_glance` / `desktop_window_list` — 화면 텍스트 설명 / 창 목록.

예: "메모장 열고 '안녕' 타이핑해줘", "지금 화면에 뭐 떠 있어?", "저 오류창 닫아줘".

동의 모드가 "항상 확인"이면 조작마다 네이티브 허용창이 뜹니다. "이 세션 동안 허용"을 누르면 그 동작은
접속기를 끌 때까지 다시 안 물어봅니다. 화면 보기(읽기전용)는 확인 없이 즉시.

**좌표 정확도**: full-res 캡처라 이미지 픽셀 = 화면 픽셀(주 모니터·100% 배율에서 1:1). 멀티모니터나
DPI 배율(125/150%)에서는 오차가 있을 수 있습니다(후속 정밀화 예정).

**백엔드**: 스크린샷 비전은 이미지를 볼 수 있는 모델이면 어디서든 동작합니다(도구 결과가 표준 이미지
블록으로 나갑니다). 비전이 없는 모델에서는 `desktop_glance`(텍스트 설명)를 쓰세요.

## 로컬 MCP 서버
1. **접속기 설정 → MCP**: 서버 추가.
   - **stdio**: 로컬 실행 명령. 예 `npx -y @modelcontextprotocol/server-filesystem /home/me/docs`
   - **http**: 이미 떠 있는 MCP 엔드포인트 URL.
   - **테스트** 버튼으로 연결 + 도구 목록 확인.
2. 에이전트는 `local_mcp_list`로 서버·도구를 발견하고 `local_mcp_call(server, tool, args)`로 호출.
   - 서버는 **추가하면 즉시** 반영(세션 재시작 불필요). 카탈로그는 호출 때마다 라이브로 가져옵니다.
3. MCP 서버 설정(명령·키·경로)은 **이 컴퓨터에만 저장**되고, 서버에는 도구 목록만 전달됩니다(프라이버시).

## 안전 모델
- 실행은 항상 이 컴퓨터에서, 접속기 동의에 따라(서버는 중계만).
- 접속기가 꺼져 있으면 도구가 "connector offline"로 안전하게 실패.
- 서버는 순수 프록시 — 로컬 MCP 설정을 저장하지 않음.

## 문제 해결
- 도구가 안 보임 / 안 쓰임 → 세션을 **재시작**했는지 확인(빌드 시점 union).
- "connector offline" → 접속기가 그 세션에 연결됐는지(오버레이가 그 세션인지) 확인.
- 조작이 안 됨 → 제어 탭에서 해당 능력이 ON인지, 동의창을 거부하지 않았는지 확인.
- 로컬 MCP가 안 뜸 → MCP 탭에서 "테스트"로 연결·도구 확인. stdio 명령의 경로/PATH 확인.
